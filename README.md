# Anik Mitra — Portfolio

Personal academic website for Anik Mitra, PhD student in Marketing at Louisiana Tech University.

Live: https://anikmitra99.github.io/anikmitra.com/

- `index.html` — the whole site (HTML, CSS and JavaScript in one file)
- `assets/Anik-Mitra-CV.pdf` — downloadable CV
- `assets/fonts/` — self-hosted Schibsted Grotesk and Literata (SIL Open Font License)

To update content, edit `index.html` and push to `main`; GitHub Pages redeploys automatically.
